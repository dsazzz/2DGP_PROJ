# 조작 디버그

이동 설계 7번의 수치는 조작감을 맞출 때 참고하는 기준값이다. 플레이로 정한 현재 값은
[`player-settings.json`](../art/player/player-settings.json)의 `movement`와 아래 표에 기록한다.

## 수평 가속

| 설정 | 이전 | 현재 |
| --- | ---: | ---: |
| `run_accel` | 10000 | 6000 |
| `air_mult` | 0.9 | 0.8 |
| `run_reduce` | 1200 | 1200 |

최고속도와 일반 가감속에 `speed_multiplier`를 한 번씩 곱한다. 현재 60Hz 고정 틱 계산상 정지 상태에서
**1~10단계 모두 지상 3틱(50ms), 공중 4틱(약 66.7ms)**에 각 단계 최고속도에 도달한다. [가속 코드](../game/objects/player.py)

1단계 지상 가속 구간의 속도는 100 → 200 → 270px/초이고 이동량은 9.5px다.
최고속도에서 키를 놓으면 170 → 70 → 0px/초로 감속하며 4px 이동한다. 이 값은 평지에서의 계산값이다.
자동 검사 항목은 `check_horizontal_acceleration`에 있다. [검사 코드](../tests/test_gameplay.py)

## 중력과 낙하

| 설정 | 이전 | 현재 1단계 |
| --- | ---: | ---: |
| `gravity` | 900 | 2700단위/초² |
| `apex_speed` | 110 | 120단위/초 |
| `max_fall` | 상한 없음 | 480단위/초 |
| `fast_max_fall` | 상한 없음 | 720단위/초 |

점프 키를 누르고 공중의 `|vy|`가 정점 기준 미만일 때 중력이 절반이 된다. 아래 키를 누르면 더 높은 낙하
상한을 적용한다. 한 틱 안에서 상한에 닿으면 남은 시간만 상한 속도로 떨어진다. [세로 이동 계산](../game/objects/player.py)

정지 상태의 공중 낙하는 일반 11틱, 아래 키를 누르면 16틱 만에 각 상한에 도달했다.

## 점프

| 설정 | 이전 | 현재 1단계 |
| --- | ---: | ---: |
| `jump_speed` | 340 | 315px/초 |
| `jump_h_boost` | 없음 | 120px/초 |
| `var_jump_time` | 없음 | 0.15초 |
| `jump_grace_time` | 시간 제한 없음 | 0.10초 |
| `action_buffer` | 0.08초 | 0.08초 |

일반 점프의 상승 시작 속도를 키를 누른 동안 최대 0.15초 유지한다. 키를 떼면 바로 중력을 적용한다.
방향키가 눌려 있으면 해당 방향으로 수평 속도 120px/초를 더한다. 속도 단계가 오르면 초속도와 수평 보정은
단계 배율만큼 커지고, 상승 유지 시간은 배율만큼 짧아진다. 코요테 타임과 착지 버퍼는 모든 단계에서 각각
100ms와 80ms다. [점프와 세로 이동](../game/objects/player.py) · [조작 설정](../art/player/player-settings.json)

60프레임 물리, 1단계 평지. 높이는 16px 타일 기준이며 체공 시간에는 착지 틱을 포함한다.

| 입력 | 이전 높이 · 체공 | 현재 높이 · 체공 |
| --- | ---: | ---: |
| 바로 뗌 | 21.33px · 267ms | 18.38px (1.15칸) · 233ms |
| 50ms 유지 | | 34.13px (2.13칸) · 333ms |
| 계속 누름 | 23.85px · 350ms | 67.13px (4.20칸) · 583ms |

10단계에서 계속 누른 점프도 67.13px이며 체공 시간은 300ms다. 현재 맵 점프 발판은 오른쪽 가장자리에
착지해 전류를 피하는 경로에서 1·10단계 모두 127.92px 도약했다. 출구 값은 `None`이다.

점프와 입력 확인만 할 때는 `python -m unittest tests.test_scene.InputTiming`을 실행한다.

## 대시

| 설정 | 이전 | 현재 |
| --- | ---: | ---: |
| `dash_speed` | 700px/초 | 700px/초 |
| `dash_duration` | 0.20초 | 0.20초 |
| `end_dash_speed` | 종료 시 수평 속도 0 | 480px/초 |
| `dash_charges` | 1회 | 1회 |

60프레임 평지에서 대시 구간은 12틱, 이동 거리는 140px(8.75칸)이다. 수평 대시가 끝나면
일반 이동의 `vx`에 ±480px/초를 넘긴다. 오른쪽 대시 후 방향키를 놓은 다음 틱은
460px/초로 감속하며 7.67px 전진한다. 대각선 종료는 가로 성분 ±339.41px/초, 수직 대시와
벽에 막힌 대시의 종료는 0이다. [플레이어 이동](../game/objects/player.py)

대시 중 X·Shift 재입력은 흡수를 먼저 시도한다. 지상에서 대시 종료까지 80ms 이내일 때는
같은 입력을 기존 `action_buffer`에 저장해, 대시를 끝낸 뒤 누를 때의 방향으로 한 번 이어 간다.
흡수에 성공하면 그 입력을 흡수 대시에 쓰고, Space·Z로 점프하면 대시와 선입력을 함께 취소한다.
60프레임에서는 종료 4틱 전(약 67ms) 입력이 이어지고 5틱 전(약 83ms) 입력은 흡수에만 쓰인다.
종료 후 새로 누르면 지상에 있거나 공중 대시 횟수가 남아 있을 때 즉시 대시한다. 확인 명령은
`python -m unittest tests.test_scene.InputTiming tests.test_scene.AbsorptionTiming`이다.
[대시 입력](../game/world/scene.py)
