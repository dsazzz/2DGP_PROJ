# 개발 기록

- 날짜 / 2026-11-21
- 단계 / 1. 고정 물리 루프 분리
- 변경 파일 / `game/core/loop.py`의 `FixedStep`, `game/main.py`의 `main`, `game/world/scene.py`의 `handle_events`·`update`, `tools/playground.py`의 `LocalLoop.run`, `tools/benchmark_electric.py`의 `main`, 관련 테스트와 문서
- 바꾼 이유 / 게임과 수동 테스트 공간에서 같은 틱 계산을 사용한다. 키다운은 다음 물리 틱에서 한 번씩 처리하고, 재불러오기에 걸린 시간은 물리 누적에서 제외한다. `--perf`에 갱신 시간을 표시한다.
- 이전 → 이후 수치 / 게임 물리 `1/60` 직접 지정 → `FIXED_DT = 1/60` 공통 사용. 전류 벤치의 1초 샘플 144개 → 60개. 화면 출력 목표 144FPS. 한 번에 누적하는 시간은 최대 0.1초다.
- 새 이름 / `PHYSICS_HZ`·`FIXED_DT`는 물리 주파수와 기존 고정 갱신 간격, `FixedStep`은 누적 시간과 기준 시각 계산, `alpha`는 한 틱에 대한 남은 시간 비율, `_queued_actions`는 점프·대시 조작과 기존 착지 버퍼에 넘길 키다운 기록에 대응한다.
- 확인 방법 / `python tools/check.py` 62개 통과. 모의 시계에서 60회 출력과 72회 고정 갱신을 실행해 `--perf`가 물리 스텝당 2.00ms를 표시하는지 확인했다. 오프스크린 전류 벤치에서 현재 맵 갱신·출력은 0.224ms/프레임이었다. 직접 플레이는 `python -m game --perf`에서 Space/Z, Shift/X, F5와 `update … ms/step`을 확인한다.
- 시간 값 점검 / 게임 코드의 144는 출력 목표, 테스트의 144Hz는 30·60·120·144Hz 비교 검증, 수동 공간의 나머지 144는 좌표·크기·색이다. 기본 주기를 따라야 하는 검사와 전류 벤치는 공통 60Hz 값을 사용한다. 전류·이펙트 프레임 번호는 초 단위 재생 시간에서 계산한다.
