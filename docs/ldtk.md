# 지형과 발판 배치 규격

## 이어 붙이는 규격

지형 한 칸은 **16×16 월드 px**다. 끊김 없이 이어지는 바닥·벽·천장은 같은 격자의 Solid 칸을
변끼리 맞닿게 칠한다. 지형 가장자리의 모서리와 테두리는 원본 타일의 투명 픽셀로 표현한다.
실제 배치가 끊겼는지는 타일 그림의 실루엣과 함께 격자의 Solid 연결을 확인한다.

| 개체 | 배치 크기 | 지형과 높이를 맞추는 기준 |
| --- | --- | --- |
| 일반 발판 | 128×16 | 사각형 윗변 |
| 통과 발판 | 96×16 | 사각형 윗변 |
| 사라짐 발판 | 112×16 | 사각형 윗변. 경고 상태도 같은 자르기 규격 |
| 이동 발판 | 96×32 | 사각형 윗변. 왕복할 양쪽 끝에서 접합 확인 |

발판의 배치 피벗은 좌측 상단 `(0, 0)`이다.
일반·통과·사라짐·이동 발판의 기본 판정 두께는 윗변부터 아래로 8px다.
발판은 8px 격자에 놓고, 지형 윗면과 이어야 할 때는 윗변을 지형의 16px 경계에 맞춘다.
개별 발판 양끝은 그림에 둥근 여백이 있으므로 연속된 바닥을 만들 때는 Solid로 이어 그린다.
미리보기의 원본 크기·투명 여백·출력 모드까지 확인해 선택 사각형과 그림이 어긋나지 않도록 한다.
배치 사각형, 원본 그림, 게임 충돌의 기준점이 가리키는 위치를 모두 비교한다.
